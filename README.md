# Human Resource Analytics Dashboard

## 📊 Project Overview
An interactive HR dashboard created using Tableau to analyze
employee demographics, salary, attrition, departments and
other HR-related metrics.

## 🛠️ Tools Used
- Tableau
- Excel
- Data Visualization
- Data Analysis
